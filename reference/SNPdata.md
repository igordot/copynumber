# Artificial SNP array data

Artificial SNP array data containing a logR track and a BAF track

## Usage

``` r
data(logR)
data(BAF)
```

## Format

Two corresponding data sets containing 10000 probes with logR and BAF
measurements, respectively, for 2 samples. The two first columns in both
data sets contain chromosome numbers and local probe positions (in base
pairs), while the subsequent columns contain logR-values and BAF-values
in the two data sets, respectively.

## Examples

``` r
#Get data
data(logR)
data(BAF)
```
